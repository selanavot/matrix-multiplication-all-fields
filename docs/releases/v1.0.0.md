# Version 1.0.0

This release archives the Lean formalization of the matrix multiplication
exponent bound **ω ≤ 9/4 over every field**, including finite fields and fields
of positive characteristic. OpenAI supplied the original 9/4 construction and
complex-field proof; this fork contributes the arbitrary-field extension.
Sela Navot directed the AI-assisted development disclosed in
[`formalization.yaml`](../../formalization.yaml).

## Reproduction and scope

Follow the root [README](../../README.md#reproduction-and-verification) from a
clean checkout of the release tag. Lean is pinned to `v4.35.0-rc2`; Mathlib is
pinned to `065356127b1dc0016f66b7283ce0ce2c4055aa55`, with all transitive
revisions in `lake-manifest.json`. Third-party binary caches may be reused by
the bootstrap procedure; the archived report describes its verification scope.

The theorem concerns asymptotic division-free arithmetic operations. It does
not supply practical constants, a bit-complexity bound, an effective uniform
program generator, or a claim of historical priority. The original arithmetic
specification is preserved. See [UPSTREAM.md](../../UPSTREAM.md) for provenance
and the separate MIT notice for the vendored fixed-point modules.
